# تطبيقات م. علي فرج

| التطبيق | المسار | الوظيفة |
|---|---|---|
| لوحة المجموعات | `/` (index.html) | المجموعات والحصص والتحصيل |
| **درجات الطلاب والمتابعة** | `/grades/` | الدرجات، الحضور، الفلوس، تقارير أولياء الأمور، الأوائل، لوحة الرسوم |

## تشغيل تطبيق الدرجات على الموبايل
1. ارفع المستودع على GitHub Pages: **Settings ← Pages ← Source: Deploy from a branch ← main / (root)**.
2. افتح من الموبايل: `https://<اسم-حسابك>.github.io/Ali_app1/grades/`
3. **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
   **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
4. التطبيق بيشتغل من غير نت، والبيانات بتتحفظ على التلفون.

## نقل بياناتك من النسخة القديمة
1. في النسخة القديمة: الطلاب ← 🛠 أدوات إضافية ← **نسخ البيانات**.
2. في التطبيق الجديد: نفس المكان ← **استرجاع (استبدال)** والصق.

## مهم
لو ما فعّلتش المزامنة (تحت)، البيانات محفوظة على التلفون بس. اعمل **⬇ حفظ ملف نسخة احتياطية** مرة في الأسبوع على الأقل وابعته لنفسك على واتساب أو Drive.

## ☁ تفعيل المزامنة مع السيرفر (Firebase) — مجاني، مرة واحدة (حوالي 10 دقايق)
1. ادخل https://console.firebase.google.com بحساب جوجل ← **Add project** ← اسم مثلًا `ali-grades` ← اقفل Google Analytics ← **Create**.
2. **Build ← Authentication ← Get started ← Email/Password ← Enable ← Save**.
3. **Build ← Firestore Database ← Create database** ← اختار مكان قريب (مثلًا `europe-west`) ← **Start in production mode**.
4. في Firestore افتح تبويب **Rules**، امسح اللي فيه والصق محتوى ملف [`grades/firestore.rules`](grades/firestore.rules) ← **Publish**.
   (القواعد دي بتخلي كل حساب يشوف بياناته هو بس.)
5. **Authentication ← Settings ← Authorized domains ← Add domain** ← اكتب `thingall38-rgb.github.io`.
6. ⚙ **Project settings ← Your apps ← أيقونة الويب `</>`** ← اسم أي حاجة ← **Register app** ← انسخ الجزء `const firebaseConfig = {...}`.
7. في التطبيق: **الطلاب ← 🛠 أدوات إضافية ← ☁ المزامنة** ← الصق الإعدادات ← **حفظ**.
8. اكتب إيميل وكلمة سر ← **إنشاء حساب** (أول مرة بس). بياناتك هتترفع تلقائي.
9. على أي موبايل تاني: نفس الخطوة 7، وبعدين **دخول** بنفس الإيميل.

> عشان ما تلصقش الإعدادات على كل جهاز: حطها في `grades/firebase-config.js` (أو ابعتها لـ Claude يحطها).
> الـ apiKey مش سر؛ الحماية الحقيقية هي القواعد في الخطوة 4 + تسجيل الدخول.

**بعد التفعيل:** أي تعديل بيترفع خلال ثانية، ولو مفيش نت بيتحفظ على الموبايل ويترفع لما النت يرجع، وفيه نسخة احتياطية يومية على السيرفر (آخر 30 يوم).
